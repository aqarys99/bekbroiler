# Дизайн админки

Экраны нарисованы в формате Design Component (`.dc.html`): обычный HTML со стилями inline, плюс `{{…}}`, `<sc-for>`, `<sc-if>` и класс `Component` с примерными данными в `renderVals()`.
Это **образец**, а не готовый код: frontend-builder переносит разметку в PHP-шаблоны, стили — в `admin.css`, примерные данные — в реальные запросы.

| Файл | Экран |
|---|---|
| `Login.dc.html` | Вход, переключатель RU / ҚАЗ |
| `Main.dc.html` | Главная: готовность к аттестации, быстрые действия, перевод, место на диске, последние новости |
| `News.dc.html` | Список новостей: поиск, фильтр по статусу, бейджи перевода |
| `NewsEdit.dc.html` | Редактор новости: вкладки Русский / Қазақша, публикация, обложка, фото, адрес |
| `Documents.dc.html` | Документы: чек-лист, категории, форма нового документа, сроки действия |
| `Gallery.dc.html` | Фотогалерея: альбомы, загрузка с очередью и сжатием, фото альбома |
| `Videos.dc.html` | Видео: YouTube или файл, список, обработка |
| `Settings.dc.html` | Настройки: тема, цвет, логотип, языки, версия для слабовидящих |

Общие элементы (одинаковы на всех экранах): левое меню, шапка с хлебными крошками и кнопкой «Открыть сайт», статусные бейджи (зелёный/оранжевый/красный/синий/серый), кнопки 44–52px.
