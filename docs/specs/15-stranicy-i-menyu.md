# 15. Страницы и меню как в WordPress

Решение пользователя; режим без planner/reviewer (см. PROGRESS «Режим работы»).

## Страницы
- Раздел «Страницы»: список (поиск по названию/адресу, фильтр «на сайте/скрыто», число документов), «Добавить страницу», правка, удаление с подтверждением.
- Поля: название RU/ҚАЗ, адрес (slug из названия через `Slug` с транслитом каз. букв, уникальный, можно править; зарезервированы адреса маршрутов сайта), вводный текст RU/ҚАЗ (editor.js + HtmlSanitizer, необязателен), «показывать на сайте».
- Старые страницы (o-nas, programma, rezhim, pitanie, usloviya) — обычные; у «Режима дня» остаётся блок расписания (`pages.has_schedule`).
- Удаление: пункты меню убираются (подпункты поднимаются), документы удаляются, файлы освобождаются в медиатеке.

## Документы страницы
- Блок «Документы» на экране страницы: добавить (название RU/ҚАЗ, файл; дата и «действует до», пункт чек-листа — необязательно; «Открывать как Читалка/Книга» — только для PDF), порядок (перетаскивание + ↑↓), изменить, заменить файл, удалить.
- Типы: PDF, DOC, DOCX, XLS, XLSX; сигнатуры (PDF: `%PDF` + finfo; docx/xlsx: zip с `[Content_Types].xml` и `word/`/`xl/`; doc/xls: OLE); лимит 20 МБ (`DocumentUploader`).
- Миграция 013: `documents.page_id` (FK CASCADE), каждая категория -> страница с тем же названием, `category_id` nullable и не используется в UI; пустые страницы «Мониторинг», «Перспективный план», «Годовой план».
- Раздел «Документы» — общий список с фильтром по странице; чек-лист аттестации и дашборд работают; «Загрузить» -> `/admin/documents/new?checklist=` (выбор страницы) -> форма на экране страницы с предвыбранным пунктом.

## Меню (Внешний вид -> Меню, только owner)
- `menu_items`: menu main|footer, parent_id, sort, type page|section|link|group, page_id, section_key (home, news, gallery, videos, staff, groups, achievements, reviews, contacts, documents), url (http/https или путь с `/`), title_ru, title_kk (необязательны для page/section), target_blank. Максимум 2 уровня, 100 пунктов.
- Экран: слева «Добавить в меню» (Страницы с поиском, Разделы, Своя ссылка, Группа), справа дерево: HTML5 drag&drop + кнопки ↑ ↓ → ←, раскрытие для правки подписей, «Удалить», переключатель «Главное/Подвал», «Сохранить меню» одним POST с JSON (CSRF, валидация, audit, сброс кэша).
- Сид: Главное — Главная · О нас · Аттестация ▸ (страницы из категорий + 3 новые) · Новости · Фотогалерея · Педагоги · Контакты; Подвал — Программа, Режим дня, Питание, Условия, Документы, Контакты.

## Сайт (все темы)
- Шапка и подвал из `menu_items` (`App\Site\SiteMenu`): скрытые/удалённые страницы и пустые разделы не показываются; группа — выпадающее меню (наведение, клик, клавиатура, `aria-expanded`), на телефоне — раскрывающийся список; активный пункт подсвечен; ҚАЗ: `title_kk` или название страницы на ҚАЗ с откатом.
- `/{slug}` и `/kk/{slug}`: заголовок, вводный текст, карточки документов (бейдж типа, дата, «Открыть», «Скачать»), пустое состояние. Старые адреса работают, `/dokumenty` — общий список по страницам, sitemap включает страницы.
- PDF: «Открыть» -> читалка/книга (фича 14). DOCX: `/dokumenty/{id}` рисует docx-preview (vendor, без CDN; при сбое — сообщение и «Скачать»). DOC/XLS/XLSX: «Открыть» в новой вкладке + «Скачать».

## Права и testid
Страницы и документы — owner и editor; меню — только owner. testid: `pages-*`, `page-docs-*`, `menu-*`, на сайте `nav-*`, `page-doc*`.

## Аттестация (15.1)
- Миграция 014: `pages.kind` (`regular` | `attestation`, по умолчанию `regular`). В `attestation` переведены страницы из категорий документов, «Мониторинг», «Перспективный план», «Годовой план» и любые страницы из группы главного меню «Аттестация». Раздел «Страницы» показывает только `regular`; `/admin/pages/{id}` страницы аттестации перенаправляет в раздел «Аттестация».
- Раздел «Аттестация» (owner и editor) — первый после «Главная» в группе «Содержимое»: список (название, число файлов, «Нет в меню», переключатель «на сайте», «Открыть на сайте», порядок ↑↓), «Создать страницу аттестации». testid `att-*`.
- Создание — одна форма без текста: название, название ҚАЗ, «Добавить в меню сайта в раздел «Аттестация»» (по умолчанию да; группа создаётся, если её нет), «Показывать на сайте», блок «Файлы» (строка: название, файл, ×; «+ Добавить ещё файл»; «Выбрать несколько файлов сразу»; «Дополнительно»: название ҚАЗ, дата, действует до, пункт чек-листа, «Открывать как» только для PDF). Пустое название = имя файла (без расширения, `_` -> пробел).
- Сохранение с JS: 1) POST `/attestation` (JSON, id), 2) файлы по одному POST `/attestation/{id}/files` (XHR, прогресс «Загружается N%» / «Готово» / «Ошибка: …» + «Повторить»; тип и размер проверяются до отправки, на сервере — finfo и сигнатуры `DocumentUploader`), 3) POST `/attestation/{id}/uploaded` -> флеш «Страница создана, загружено N из M файлов» и переход на экран правки. Кнопка блокируется, при уходе во время загрузки — предупреждение; при ошибках остаются «Повторить» и «Перейти к странице».
- Без JS: multipart с `files[]`, `titles[]` (+ `titles_kk[]`, `doc_dates[]`, `valid_untils[]`, `checklist_keys[]`, `view_modes[]`) и `multi[]`, до 30 файлов; при превышении `post_max_size` (`Guard`) — редирект с флешем «Слишком много файлов за раз, добавьте часть файлов после сохранения».
- Правка: название RU/ҚАЗ, «показывать на сайте», удаление страницы (подтверждение; пункты меню убираются, файлы освобождаются); список файлов (изменить/«Дополнительно», заменить, удалить, порядок drag&drop и ↑↓) и тот же блок добавления с загрузкой по одному.
- Порядок страниц: источник — `pages.sort` среди `attestation`. ↑↓ в разделе «Аттестация» переписывает порядок пунктов страниц внутри группы меню (прочие пункты группы остаются на местах). Если владелец сохранил меню вручную, порядок страниц аттестации берётся из группы «Аттестация» (`MenuItem::syncAttestationFromMenu`): побеждает последнее действие.
- Сайт: страница аттестации — заголовок и карточки файлов без текста и подзаголовка «Документы»; PDF -> читалка/книга, DOCX -> просмотр, DOC/XLS/XLSX -> новая вкладка + «Скачать».
- Чек-лист: «Загрузить» -> `/admin/attestation/choose?checklist=` -> страница -> форма добавления с предвыбранным пунктом (`/documents/new` перенаправляет туда). Действие «Загрузить документ» на дашборде ведёт в раздел «Аттестация».
